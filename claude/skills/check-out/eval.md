# check-out eval

Run as a self-check after completing the wrap-up routine (Step 9). Answer each check PASS or FAIL. If FAIL, note the issue - some are worth fixing now, others are just observations for `memory.md`.

## Journal quality

1. Are journal entries under concrete `##` headings - not dumped as a wall of bullets under the main heading?
2. Does every logged item name what was done specifically - not "worked on the project" or "continued yesterday's thing"?
3. Is the reflection section complete - all four questions answered, even if brief?

## Tomorrow prep

1. Are carryover TODOs actionable tasks, not vague intentions? ("Write the check-in eval.md" not "keep working on the skill")
2. Does tomorrow's journal seed contain only confirmed carryovers - nothing invented or assumed?

## Highlights

1. Were highlights flagged only for genuinely notable items (shipped work, recognition, decisions, notable outcomes) - not routine daily tasks?
2. If no highlights were found, was the question skipped entirely (not asked and answered "nothing")?

## Process

1. Was the NornicDB store attempted only after the wiki writes succeeded - never before, never in place of them?
2. Was the daily personal check-in rotation folded in only if it wasn't already resolved today - never asked twice?
